# FlowTube - حمل ببساطة

موقع تحميل محتوى بسيط ونظيف.

## النشر على Vercel

1. ارفع المشروع على GitHub
2. ادخل على Vercel
3. اضغط Import Project
4. اختار المستودع
5. Vercel هيبني وينشر تلقائياً

## الروابط بعد النشر

- الموقع: https://your-project.vercel.app
- API: https://your-project.vercel.app/api

## ملاحظات

- التحميل يعمل مباشرة في المتصفح
- الجودات المجانية: 360p و 480p
- الجودات المدفوعة: 720p و 1080p
- الدفع: فودافون كاش، أورانج كاش، اتصالات كاش، وي كاش
